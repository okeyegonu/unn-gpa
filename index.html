Enter your courses, then add each grade as the result is released. A course joins the GPA only when you choose a grade for it — leaving it at — keeps it dormant, contributing no units and no points. A grade of F is different: it scores 0 points, but its units still count towards the denominator. Grades are A = 5, B = 4, C = 3, D = 2, E = 1, F = 0 across the whole University.
